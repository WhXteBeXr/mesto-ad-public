## Технологии

- HTML5, CSS3
- JavaScript (ES Modules)
- Vite

## Команды

Установка зависимостей:
```
npm install
```

Запуск локального сервера разработки:
```
npm run dev
```

Сборка проекта:
```
npm run build
```

Публикация на GitHub Pages:
```
npm run deploy
```
